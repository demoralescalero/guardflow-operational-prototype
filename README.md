GuardFlow — Prototipo Operativo
Prototipo navegable de una plataforma de control operativo para empresas de seguridad.

Esta es una maqueta interactiva con datos simulados. Su objetivo es demostrar flujos operativos, arquitectura de información y experiencia de usuario; no es todavía una aplicación de producción.

Demo
Abre index.html directamente en un navegador moderno cuando GitHub Pages esté activado. La maqueta podrá visualizarse desde un enlace público.

Módulos incluidos.-

-Dashboard: estado general de operación, agentes activos, alertas y sedes.
-Asistencia: marcación de entrada y salida con evidencia y validación GPS simuladas.
-Rondas QR: recorrido de vigilancia, puntos de control y progreso de ronda.
-Ocurrencias: registro trazable de novedades con evidencia simulada.
-Botón de pánico: flujo de alerta operativa y atención por supervisión.
-Informes: vista de reportes descargables por período y sede.

Tecnologías del prototipo:

-HTML5
-CSS3 responsive
-JavaScript vanilla
-Datos ficticios para demostración

No requiere instalación, dependencias ni servidor local para la maqueta.

Alcance y limitaciones
La maqueta muestra la experiencia de navegación y los flujos operativos esperados. Los botones, formularios, GPS, cámara, lector QR, almacenamiento de evidencia e informes son demostrativos; no persisten datos ni se conectan a servicios externos.

Próximos pasos.-

-Autenticación y roles: administrador, supervisor, agente y cliente.
-Base de datos y almacenamiento de fotos/videos.
-Geolocalización, geocercas y validación de asistencia.
-Escáner QR mediante cámara móvil.
-Notificaciones y alertas en tiempo real.
-Exportación real de informes PDF y Excel.

Flujo de demostración:

-El supervisor revisa el dashboard y detecta alertas.
-El agente registra asistencia con ubicación y evidencia.
-Inicia una ronda y escanea puntos QR.
-Registra una ocurrencia cuando detecta una novedad.
-Activa el botón de pánico ante una situación crítica.
-El supervisor consulta y descarga el informe operativo.

Aviso
Todos los nombres, ubicaciones, porcentajes, horarios y registros mostrados son ficticios y se usan únicamente para fines de demostración.
